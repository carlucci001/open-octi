# Environment reference

This lists configuration names only. It never contains saved values.

- `CRM_SESSION_SECRET` — Required - replace all six values
- `INITIAL_ADMIN_PASSWORD` — Optional OpenOcti configuration.
- `PUBLIC_APP_URL` — Optional OpenOcti configuration.
- `OPENOCTI_BUSINESS_NAME` — Optional OpenOcti configuration.
- `OPENOCTI_OWNER_NAME` — Optional OpenOcti configuration.
- `OWNER_EMAIL` — Optional OpenOcti configuration.
- `CRM_DATA_DIR` — OpenOcti defaults - leave unchanged
- `DATA_BACKEND` — Optional OpenOcti configuration.
- `FCC_EDITION` — Optional OpenOcti configuration.
- `NEXT_PUBLIC_FCC_EDITION` — Optional OpenOcti configuration.
