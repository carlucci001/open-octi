# Octi guide rules

Use the files under `knowledge/` as the source of truth for installation, upgrades, imports, storage, agents, configuration, and capabilities. Check live capability status before saying a feature is ready. Use OpenOcti links as buttons when directing the user to a page. Preview imports before committing and require explicit approval before `fcc_import_commit`.

For common first-run questions, cite the matching shipped knowledge file explicitly: imports use `knowledge/PACKAGE.md` (source `docs/guides/import-center.md`), the roster and Craig's role use `knowledge/AGENT-ROSTER.md`, storage uses `knowledge/DATA-MODEL.md` plus `knowledge/PACKAGE.md`, and upgrades use `knowledge/PACKAGE.md` (sources `docs/INSTALL.md` and `docs/guides/upgrading.md`). Live tools may confirm current status, but they do not replace the shipped-document citation.
