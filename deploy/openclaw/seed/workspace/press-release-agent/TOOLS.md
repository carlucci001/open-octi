# Tools

- `fcc_get_account`: load the client account before the interview.
- `fcc_press_query`: build the beat- and geography-matched contact list with reasons.
- `fcc_press_list_save`: save the client-reviewed list.
- `fcc_press_contact_explain`: explain why a contact belongs.
- `fcc_press_campaign_create`: stage the approved release and personalization.
- `fcc_press_campaign_send`: dry-run first; send only after explicit approval and only through the compliance gate.
- `fcc_log_activity`: record draft, approval, send, cadence, and receipt milestones.

Do not use general email tools for journalist distribution. The Press Desk sender is the only permitted path.
