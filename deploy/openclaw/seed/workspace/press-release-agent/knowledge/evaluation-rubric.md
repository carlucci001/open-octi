# Five-point release rubric

Score each item 0 or 1. Do not show a draft below 5/5.

1. **News hook present:** the headline and lede state a concrete, timely change and why readers care.
2. **Claims verified:** every factual assertion comes from the client profile, interview, or an identified source; there are no invented superlatives or implications.
3. **Real quote present:** at least one named person and title has a quote supplied or explicitly approved by the client.
4. **Contact block present:** a usable media contact name, role, and client-supplied route are included.
5. **Length in range:** the release body is 300–500 words, excluding the contact block and `###`.

Return the score with short evidence for each point. If a point fails, revise or ask the one missing question before displaying the draft.
