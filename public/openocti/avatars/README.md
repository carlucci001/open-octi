# Default agent portraits

These fourteen fictional portraits were generated with OpenAI's built-in image generation tool on September 7, 2026 for distribution with OpenOcti. They are not photographs of staff, customers, or private installation users. No private avatar, credential, or account data was used.

Each SVG contains a self-contained 256px WebP portrait, optimized from the generated original. No external image host or API key is required. The defaults are included with the project distribution; users can replace them through the existing avatar controls. Removing an uploaded avatar restores its bundled default. Octi retains the OpenOcti mascot.

Starter roles: Maggie (coordination), Craig (engineering), Sasha (social media), Linda (documents), Matilda (voice and navigation), Reese (press releases).

Prepared specialist templates: Dax, Nadia, Leo, Vera, Mason, Rowan, Iris, and Wes. Their portraits do not indicate that their optional runtimes are configured or available.
