# OpenOcti 1.2.3 — Your workspace, your agents

OpenOcti brings your repository, conferencing, and specialist agents into one self-hosted workspace. This release polishes the first-run experience and makes connection requirements clearer.

## Included in the package

- **Gitea repository workspace:** Docker Compose includes Gitea with separate persistent storage. Open Repository and use your OpenOcti identity to create or import repositories. Direct Git SSH/HTTPS transport is not exposed by default; see the [repository setup guide](../INSTALL.md#repository-workspace).
- **Daily video conferencing:** connect your own Daily account and API key to create and join video rooms. Email invitations also require Resend configuration. Choose your providers' plans for your own usage; OpenOcti does not include conferencing credits.
- **Specialist agents:** Maggie, Craig, Sasha, Linda, Matilda, and Reese ship with their packaged knowledge and distinct default portraits. Octi keeps the octopus mascot. Eight prepared specialist templates also have portraits; optional runtimes still require configuration.
- **Fourteen bundled headshots:** artwork ships in the GitHub source and Docker app image, works offline, and needs no API key or first-run generation. Uploaded and legacy custom avatars take precedence. Removing an uploaded avatar restores the default.

## Improvements in this release

- OpenAI realtime sessions feed the header audio meter and expose a compact Resume audio action when browser playback is blocked. Failed responses, stale session callbacks, and connection closure receive clearer handling. The existing Go Live and agent dropdown remain available.
- Owners can return to Admin for provider setup, including Stripe. Stripe credentials are stored encrypted; the [Stripe guide](../guides/stripe-setup.md) explains the working payment flows and the catalog/subscription steps performed in Stripe Dashboard.
- Optional workspace navigation bars can be turned on or off from the account menu and start disabled in a fresh installation.
- Money Console, Incident Inbox, and Ship Desk explain unavailable public-build services instead of implying that private monitoring and deployment backends are connected. The Money Console platform-data crash is corrected.
- Image generation uses the saved OpenAI key. Automation controls and media planning interactions receive UI fixes.
- Docker image publication now waits for the same full CI verification used by release pull requests, including the public boundary and secret checks.

## Help choose what comes next

OpenClaw is included. **Hermes is planned for a future release.** Harness Lab includes a small [Star OpenOcti on GitHub](https://github.com/carlucci001/open-octi) link beside Hermes, DeerFlow, and DeepSeek Harness so you can support continued integration work. DeerFlow uses the optional research profile; DeepSeek Harness requires a separately configured runtime. A GitHub star does not install or enable a harness.

## Current limits

Provider accounts, API keys, and usage costs belong to each installation. Automated Stripe catalog provisioning, subscription webhook reconciliation, the private portfolio/deployment backends, and an OpenMontage rendering adapter are not included in this release. Browser microphone permissions and audio playback policies still apply to voice. See [installation](../INSTALL.md) and the in-app setup guidance before a live demonstration.
