# OpenOcti 1.3.0

This release adds a bundled Postiz installation and setup help that remains available before you connect an AI provider.

- Docker Compose includes pinned Postiz, PostgreSQL, Redis, and Temporal services with persistent storage and health checks. Run the Postiz setup script before starting the stack.
- Create your own local administrator account on first launch. There is no shared default password.
- Save your installation's Postiz connection in dedicated settings. API keys are encrypted and never displayed in setup diagnostics.
- Ask Octi includes searchable written instructions, reading progress, service checks, and recovery steps without an AI key. Configured providers add conversational answers; existing voice help remains available.
- Installation, connection, scheduling, and publication are shown as separate states. A connection check or scheduling receipt is not proof that a post appeared on a social network.
- Existing voice agents, authored knowledge, portraits, repository access, Stripe configuration, workspace layout preferences, and inline campaign drawers are retained.
- The displayed version now follows the exported package version.

## Installing and upgrading

Follow the [getting-started guide](../guides/getting-started.md). Back up your existing data and configuration before upgrading. Run `node scripts/setup-openocti-postiz.mjs`, validate Compose configuration, and recreate the services without removing their named volumes.

Postiz installation does not authorize a social platform or connect an account automatically. Connect your own accounts and verify a reviewed image-and-caption test on the destination platform. Plain Node installations require separately managed sidecar services.

This package uses only its installation's configuration, accounts, and credentials. It does not include private business records or access to Farrington services.

## Verification scope

Installation, first-account setup, keyless help, connection diagnostics, restart persistence, and the pinned Postiz request contract were checked in independent installations. Automated tests cover image-upload and publishing failures. A live Facebook Page publication and a live OpenAI help response were not performed for this release because those installations have no authorized provider credentials. Configure your own accounts and complete the guide's destination check before relying on live publication.
