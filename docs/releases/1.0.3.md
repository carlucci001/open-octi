# OpenOcti 1.0.3

OpenOcti 1.0.3 is a privacy and edition-boundary patch release.

## Changes

- Replaced the Builder workspace with a roadmap card in the open edition while preserving the full Command Center Builder experience.
- Made every Builder API route return `404 Not Found` in the open edition.
- Expanded export privacy enforcement for telephone links, US phone numbers, personal location, and owner identifiers.
- Added optional workspace phone and website fields for OpenOcti email signatures; missing contact fields are omitted.

There are no database migrations or required configuration changes for this patch release.
