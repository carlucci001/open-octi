# OpenOcti 1.1.0

OpenOcti 1.1.0 turns a fresh install into a guided, populated workspace.

This release also includes the 1.0.2 and 1.0.3 privacy hotfixes: Farrington-internal product modules and references remain excluded from the open edition, exports fail closed on denylisted content, the Builder uses its public coming-soon card, and personal contact details are neutralized.

## Highlights

- Save and test Anthropic, OpenAI, Gemini, OpenRouter, and optional ElevenLabs keys in the app; values are encrypted at rest and never returned as plaintext.
- OpenClaw applies app-saved model keys through its watched shared configuration without a container restart.
- A four-step dashboard checklist guides workspace naming, model setup, agents, and imports.
- Prerecorded OpenOcti welcome audio replaces browser speech on first run.
- Ten synthetic sample records per core business object are installed by default and can be removed safely with one switch.
- The Import Center supports CSV, XLSX, and vCard mapping, presets, validation, dedupe, batch undo, templates, and owner CSV exports.
- Octi joins the starter staff as a package-grounded onboarding guide with live capability, roster, page, and import tools.
- OpenOcti branding now uses the official octopus mark and OpenOcti wordmark throughout the public edition.

## Upgrade note

Back up the named `/data` volume before rebuilding. Existing user records and OpenClaw workspace files are preserved. Sample removal filters only records explicitly marked `sample: true`.
