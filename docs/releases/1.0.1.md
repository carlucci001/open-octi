# OpenOcti 1.0.1

OpenOcti 1.0.1 is a patch release focused on public-release reliability and accurate OpenOcti branding.

## Changes

- Public CI is green on Linux. Exported tests now use the public demo-data layout and handle cross-platform paths consistently.
- The repository banner uses the real OpenOcti octopus mark, embedded so it renders reliably on GitHub.
- OpenOcti gateway logs now identify the runtime as `openclaw-gateway` instead of the deployment-specific Hetzner label.
- Public exports are version-stamped. Release exports require `--version X.Y.Z` (or `OPENOCTI_VERSION`), update package metadata, and include `VERSION.json`; development exports use `--dev` and `0.0.0-dev`.
- Documented and verified the Node (no Docker) install path.

There are no database migrations or configuration changes required for this patch release.
