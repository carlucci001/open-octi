# OpenOcti 1.2.0

- Settings → Integrations shows connection requirements and lets administrators test configured providers.
- Video meetings, domain management, payments, and social publishing explain missing connections before provider actions start.
- Settings → Monitoring adds application, Cloudflare, and Nylas checks, SQLite history, optional failure/recovery alerts, and a five-minute Linux timer template.
- Stored communications and workflow definitions stay available without unrelated provider keys.

Back up the installation's data volume before upgrading. Monitoring uses your installation's own environment and starts on demand; enable the provided timer for recurring checks. See [Connection monitoring](../guides/MONITORING.md).
