# OpenOcti 1.2.4

OpenClaw dashboard links stay on the current OpenOcti installation instead of redirecting to a placeholder domain. The Docker app uses its configured gateway for dashboard assets and an authenticated WebSocket connection. Dashboard access requires an active administrator session and a matching browser origin.

Postiz connection checks now use the configured Public API URL once, send the correct authorization header, and verify that the response contains channels. The test reports channel counts and explicitly says publishing has not been tested. Placeholder addresses no longer silently route to an assumed local Postiz server. Social publishing displays channel connection errors and describes the separate server requirement.

Postiz is not bundled with the standard Docker stack. Follow the [setup guide](../guides/postiz-setup.md). Social-account authorization and a real publishing acceptance test remain required. This update does not add a Postiz server or change the gateway version, agents, voice settings, or private Command Center deployment.
