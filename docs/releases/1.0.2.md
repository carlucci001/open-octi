# OpenOcti 1.0.2

OpenOcti 1.0.2 is a privacy hotfix for the public edition.

## Changes

- Removed Farrington-internal Platforms/SearchTools3/VideoHub/Newsroom modules and product references from the open edition; export now refuses to ship them.
- Added an export-wide product-reference denylist with file-and-line diagnostics.

There are no database migrations or configuration changes required for this patch release.
